SPDX usage
------------

BoBa-owned source, build, and script files use SPDX tags instead of repeating
the full license text. The SPDX license expression for BoBa-owned files is:

    SPDX-License-Identifier: Apache-2.0 WITH LLVM-exception

This enables machine processing of license information based on the SPDX
License Identifiers that are available here: https://spdx.org/licenses/

Files that come from third-party projects keep their upstream license markings.
