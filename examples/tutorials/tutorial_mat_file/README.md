# BOBA/MATLAB IO Tutorial

Demonstrates how to share data between the `TensorTrain`/`TensorTrainMatrix`
objects in BOBA and `tt_tensor`/`tt_matrix` objects in the
[TT-Toolbox MATLAB code](https://github.com/oseledets/TT-Toolbox) by
Oseledets et al.

## Step 0

Launch MATLAB and create a `tt_toolbox_root` variable pointing to the root of
the root of the cloned TT-Toolbox repository, e.g.

```matlab
tt_toolbox_root = '~/tt-toolbox';
```

## Step 1

Run the `step_1_generate_objects` script.

This script creates a TT vector $x$ obtained by sampling the sine function, and
a corresponding TT operator $A$ to compute derivative using the midpoint rule.
These objects are then converted to cell arrays and saved to MAT files.

## Step 2

Compile the `step_2_modify_objects.cpp` program by running
`make tutorial_mat_file BOBA_MATLAB=1` in the root directory of the BOBA
project. You may need to modify the MATLAB paths and environment variables as
suggested in the `Makefile_boba` file. This will create an executable inside
*this* tutorial directory.

Running the executable will load the $A$ and $x$ objects into memory. BOBA then
computes the vector $y = A x$ in TT format. It also constructs the TT operator
$B$ corresponding to the negative Laplacian on a 4D grid, and applies it to a
full vector $t$ to compute the full vector $z = B t$. Both $B$ and $t$ objects
are saved to MAT files.

## Step 3

Run the `step_3_verify_objects` script inside MATLAB.

This script recreates the $A$ and $x$ objects from step 1, and mimics the
$y = A x$, $B$ and $z$ computations from step 2 using TT-Toolbox functions.
Finally, the values of these three objects are read from the MAT files
generated by BOBA in step 2, and compared against those computed in MATLAB.

## Miscellaneous Scripts

Two scripts are available for saving MATLAB arrays in `boba_print` type format:
`boba_print_vector` and `boba_print_tensor`. The `boba_print_example` script
outlines some example usage.
